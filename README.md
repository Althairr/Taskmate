# TaskMate - Kelompok 5

TaskMate adalah aplikasi manajemen tugas yang memungkinkan pengguna untuk mengelola tugas mereka dengan mudah. Aplikasi ini dibuat menggunakan Kotlin serta memakai Firebase sebagai backend untuk autentikasi dan penyimpanan data. 

TaskMate dirancang untuk menawarkan solusi
yang lebih sederhana dan intuitif, dengan fitur-fitur yang mendukung penjadwalan,
pengingat, serta pengelompokkan tugas, sehingga dapat meningkatkan efisiensi
manajemen tugas dengan baik. Aplikasi ini berusaha untuk meningkatkan
produktivitas dan memastikan bahwa setiap tugas dapat diselesaikan tepat waktu.

## Fitur TaskMate (yang sudah diimplementasikan)

- **Autentikasi Pengguna**: Pengguna sudah dapat mendaftar dan masuk menggunakan email dan kata sandi. 
- **Reset Kata Sandi**: Pengguna dapat mereset kata sandi mereka jika lupa. Cara kerja untuk fitur ini nantinya pengguna akan memasukkan email. Lalu setelah dikirim, pengguna akan menerima tautan verifikasi untuk mengganti passwordnya.
- **Manajemen Tugas**: Pengguna sudah bisa melakukan pembuatan task (Create) dan sudah bisa melihat task (Read) di bagian Homepagenya.
- **Memperbarui Profil**: Pengguna sudah bisa melakukan pergantian nama, apabila ada salah ketik. Nantinya nama pengguna akan diperbarui (Update).
